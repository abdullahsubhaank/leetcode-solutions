# Problem: Move Zeroes (Easy)
**Link:** [https://leetcode.com/problems/move-zeroes/](https://leetcode.com/problems/move-zeroes/)

### Approach
In-place two pointer partition. We move all 0's to the end of `nums` while maintaining the relative order of non-zero elements.
### Complexity
- **Time:** O(n)
- **Space:** O(1)
