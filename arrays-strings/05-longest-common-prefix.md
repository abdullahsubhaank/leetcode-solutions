# Problem: Longest Common Prefix (Easy)
**Link:** [https://leetcode.com/problems/longest-common-prefix/](https://leetcode.com/problems/longest-common-prefix/)

### Approach
Vertical scanning character by character. We find the longest common prefix string amongst an array of strings by using vertical scanning across characters at matching indices.
### Complexity
- **Time:** O(S) where S is the sum of all characters in all strings.
- **Space:** O(1)
