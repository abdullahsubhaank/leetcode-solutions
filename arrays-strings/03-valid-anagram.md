# Problem: Valid Anagram (Easy)
**Link:** [https://leetcode.com/problems/valid-anagram/](https://leetcode.com/problems/valid-anagram/)

### Approach
Character frequency count via hash map. We determine if `t` is an anagram of `s` by checking their lengths first, and then comparing character frequency counts.
### Complexity
- **Time:** O(n)
- **Space:** O(1)
